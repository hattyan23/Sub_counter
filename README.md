# 登録者数カウンター

YouTube チャンネルの登録者数を、OBS の配信画面に表示する Windows 用のツールです。
YouTube Data API v3 を使って数字を取得します。

**このツールは YouTube や Google が提供・公認するものではありません。**

## できること

- 登録者数を OBS のブラウザソースに表示（背景は透明）
- フォント・色・縁取り・位置の変更
- 数字が変わるときのアニメーション（増えると上へ、減ると下へ）と、増えたときの演出
- 背景に画像・動く画像・動画を設定

## 使い方

配布 zip の中の「導入ガイド.pdf」をご覧ください。
API キー（無料）は、各自の Google アカウントで作成していただく必要があります。
