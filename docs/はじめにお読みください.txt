======================================================
 YouTube 登録者数カウンター  導入手順
======================================================

YouTube チャンネルの登録者数を、OBS の配信画面に表示するツールです。
YouTube 公式の API（YouTube Data API v3）を使って数字を取得します。

導入は 5 ステップです。最初に Google のサイトで「API キー」を
1 つ作る必要がありますが、手順どおりに進めれば大丈夫です。
API キーの作成と、この使い方の範囲で料金はかかりません。


------------------------------------------------------
 表示される数字について
------------------------------------------------------

 YouTube の仕様で、登録者が 1,000 人を超えると、上から 3 桁より下は
 切り捨てられた数字になります。

   実際の登録者数       表示される数字
          999                999
        1,234              1,230
       12,345             12,300

 そのため 1,000 人を超えると 10 人ごと、10,000 人を超えると
 100 人ごとにしか数字が動きません。故障ではありません。

 また、YouTube 側の数字が更新されるまで時間がかかるため、
 登録者が増減しても、すぐには画面が変わらないことがあります。


------------------------------------------------------
 始める前に用意するもの
------------------------------------------------------

 [ ] Windows のパソコン（Windows 10 / 11）
 [ ] OBS Studio
     入っていない場合は https://obsproject.com/ja/ から
     インストールしてください。
 [ ] Google アカウント（API キーを作るために使います）


------------------------------------------------------
 ステップ 1：API キーを作る（最初の 1 回だけ）
------------------------------------------------------

 Google のサイトの画面は変わることがあります。見つからないときは、
 似た名前の項目を探してください。

 1. https://console.cloud.google.com/ を開き、Google アカウントで
    ログインします。
    初めての場合は、利用規約に同意します。

 2. 画面上部のプロジェクト選択から「新しいプロジェクト」を選びます。
    名前は何でもかまいません（例：youtube-counter）。
    「作成」を押し、作ったプロジェクトを選択します。

 3. 左上のメニューから「API とサービス」→「ライブラリ」を開きます。

 4. 「YouTube Data API v3」を検索して選び、「有効にする」を押します。

 5. 「API とサービス」→「認証情報」を開きます。

 6. 「認証情報を作成」→「API キー」を選びます。
    API キー（長い英数字）が表示されます。

 7. 安全のため、キーの設定で次のように制限します。
      「API の制限」→「キーを制限」→「YouTube Data API v3」だけを選ぶ
    「保存」を押します。

 ★ API キーは、パスワードと同じように大切に扱ってください。
    人に教えたり、配信画面に映したりしないでください。


------------------------------------------------------
 ステップ 2：チャンネル ID を調べる（最初の 1 回だけ）
------------------------------------------------------

 1. https://www.youtube.com/account_advanced を開きます。
    （登録者数を表示したいチャンネルでログインしてください）

 2. 「チャンネル ID」の欄の文字をコピーします。
    「UC」で始まる 24 文字です。


------------------------------------------------------
 ステップ 3：ツールを起動して設定する（最初の 1 回だけ）
------------------------------------------------------

 1. ダウンロードした zip ファイルを右クリックして「すべて展開」を
    選び、「展開」を押します。
    ※ zip を開いただけの状態では正しく動きません。

 2. 展開したフォルダーの「YouTubeSubCounter.exe」をダブルクリックします。
    「_internal」フォルダーは消したり移動したりしないでください。

 3. 青い画面で「Windows によって PC が保護されました」と出た場合は、
    「詳細情報」→「実行」の順にクリックします。
    （個人が配布しているソフトのため表示されることがあります）

 4. 案内のメッセージが出るので「OK」を押します。
    メモ帳で設定ファイルが開きます。

 5. 2 か所の "" の中に貼り付けます。

      "api_key": "ここに API キーを貼る",
      "channel_id": "ここにチャンネル ID を貼る",

    " は消さないでください。

 6. メモ帳で「ファイル」→「保存」を選び、メモ帳を閉じます。
    自動で数字の取得が始まります。

 ツールには画面がありません。画面右下のタスクトレイ（時計の近く）に
 赤いアイコンとして常駐します。見当たらないときは、時計の近くの
 「^」をクリックしてください。


------------------------------------------------------
 ステップ 4：OBS に表示する（最初の 1 回だけ）
------------------------------------------------------

 1. OBS を開きます。

 2. 画面下の「ソース」欄にある「+」をクリックします。

 3. 「ブラウザ」を選びます。

 4. 名前に「登録者数」などと入力して「OK」をクリックします。

 5. 設定画面の「URL」欄を、次の内容に書き換えます。

      http://localhost:8765/

    幅と高さは変更しなくてかまいません。

    ヒント：URL は、タスクトレイの赤いアイコンを右クリックして
            「OBS 用の URL をコピー」を選ぶと、コピーできます。

 6. 「OK」をクリックします。


------------------------------------------------------
 ステップ 5：表示を確認する
------------------------------------------------------

 1. 数字が表示されたら、YouTube Studio の登録者数と同じか
    確認してください。

 2. プレビュー画面の中で、ドラッグして位置や大きさを調整します。
    文字は枠の大きさに合わせて拡大・縮小します。

 これで導入は完了です。


======================================================
 毎回の使い方
======================================================

 配信を始めるとき
   1. 「YouTubeSubCounter.exe」をダブルクリック
   2. OBS を起動

 配信が終わったら
   タスクトレイの赤いアイコンを右クリックして「終了」を選ぶ

 ※ ツールを起動していないと、OBS に数字は表示されません。


======================================================
 知っておくと安心なこと
======================================================

 ・数字の確認は 1 分ごとです。API の無料枠（1 日 10,000 回）の
   範囲に十分収まります。

 ・一度数字が表示されたら、問題が起きても OBS にエラーは出ず、
   直前の数字を表示し続けます。
   原因はタスクトレイのアイコンのメニューで確認できます。

 ・API キーは、このパソコンの中の設定ファイルにだけ保存されます。


======================================================
 困ったときは
======================================================

 Q. OBS に「API キーとチャンネル ID を設定してください」
    「API キーを確認してください」「チャンネル ID を確認してください」
    と出ている
    タスクトレイの赤いアイコンを右クリックして「設定を開く」を選びます。
    内容を直して保存すると、自動でやり直します。
    前後に余計な空白が入っていないかも確認してください。
    「API キーを確認」と出るときは、ステップ 1 の 4 の「有効にする」が
    終わっているかも確認してください。

 Q. OBS に「登録者数が非公開になっています」と出ている
    YouTube の設定でチャンネルの登録者数を公開にしてください。
    公開にしたら、ツールをいったん終了して起動し直します。

 Q. OBS に「---」と出ている
    インターネットの不調などで、まだ数字を取得できていません。
    自動でやり直すので、そのままお待ちください。
    原因はアイコンのメニューの一番上に表示されます。

 Q. OBS に何も表示されない
    次の順に確認してください。
    1. タスクトレイに赤いアイコンがありますか？
       なければ exe を起動してください。
    2. OBS の URL は http://localhost:8765/ になっていますか？
       すべて半角で、打ち間違いがないか確認してください。
    3. OBS のソース一覧で、ブラウザソースが非表示
       （目のマークが消えた状態）になっていませんか？

 Q. 数字がしばらく変わらない
    登録者数が変わっていないか、YouTube 側の更新待ちです。
    1,000 人を超えている場合は「表示される数字について」も
    読んでください。

 Q. 「API の 1 日の上限に達しました」と表示された
    API の無料枠を使い切っています。翌日（日本時間の 16 時か 17 時）に
    自動で再開します。同じ API キーを他のツールでも使っている場合は、
    分けると起きにくくなります。

 Q. 「すでに起動している可能性があります」と表示された
    ツールはすでに動いています。もう一度起動する必要はありません。
    タスクトレイに赤いアイコンがない場合は、パソコンを再起動してから
    試してください。

 Q. 起動したのに何も表示されない
    このツールには画面がありません。タスクトレイに赤いアイコンが
    あれば、正常に動いています。

 Q. ツールを削除したい
    1. タスクトレイのアイコンから「終了」を選びます。
    2. 展開したフォルダーをごみ箱に入れます。
    3. キーボードの「Windows キー」と「R」を同時に押します。
    4. 次の文字を入力して「OK」をクリックします。
         %LOCALAPPDATA%
    5. 開いたフォルダーの中の「YouTubeSubCounter」を削除します。
       これで API キーの設定も消えます。
    6. 不要になった API キーは、Google Cloud の「認証情報」の画面で
       削除してください。
