======================================================
 登録者数カウンター  導入手順
======================================================

YouTube チャンネルの登録者数を、OBS の配信画面に表示するツールです。
YouTube 公式の API（YouTube API Services）を使って数字を取得します。

このソフトは YouTube や Google が提供・公認するものではありません。


------------------------------------------------------
 表示される数字について
------------------------------------------------------

 YouTube の仕様で、登録者が 1,000 人を超えると、上から 3 桁より下は
 切り捨てられた数字になります。

   実際の登録者数       表示される数字
          999                999
        1,234              1,230
       12,345             12,300

 そのため 1,000 人を超えると 10 人ごと、10,000 人を超えると
 100 人ごとにしか数字が動きません。故障ではありません。


------------------------------------------------------
 始める前に用意するもの
------------------------------------------------------

 [ ] Windows のパソコン（Windows 10 / 11）
 [ ] OBS Studio（https://obsproject.com/ja/）
 [ ] Google アカウント


------------------------------------------------------
 ステップ 1：ツールを起動する（最初の 1 回だけ）
------------------------------------------------------

 1. ダウンロードした zip ファイルを右クリックして「すべて展開」を
    選び、「展開」を押します。
    ※ zip を開いただけの状態では正しく動きません。

 2. 展開したフォルダーの「SubCounter.exe」をダブルクリックします。
    「_internal」フォルダーは消したり移動したりしないでください。

 3. 青い画面で「Windows によって PC が保護されました」と出た場合は、
    「詳細情報」→「実行」の順にクリックします。
    （個人が配布しているソフトのため表示されることがあります）

 4. ブラウザーで「初期設定」の画面が自動で開きます。


------------------------------------------------------
 ステップ 2：初期設定の画面に入力する（最初の 1 回だけ）
------------------------------------------------------

 画面の案内に沿って進めます。

 1. 利用規約とプライバシーポリシーを読み、チェックを入れます。

 2. 画面のリンクから Google Cloud を開いて API キーを作り、
    貼り付けます。
    ※ 画面ごとの詳しい手順と、うまくいかないときの直し方は
       「導入ガイド.pdf」の「API キーの作り方」（6〜9 ページ）に
       載っています。お金はかかりません。

    ★ API キーはパスワードと同じです。
       人に教えたり、配信画面に映したりしないでください。

 3. チャンネルのハンドル（@ で始まる名前）か、チャンネルページの
    URL を貼り付けます。

 4. 「保存して確認する」を押します。
    「確認できました。登録者数：○○」と出れば成功です。
    問題があるときは、その場で理由が表示されます。


------------------------------------------------------
 ステップ 3：OBS に表示する（最初の 1 回だけ）
------------------------------------------------------

 1. OBS の「ソース」欄にある「+」→「ブラウザ」を選びます。

 2. 名前に「登録者数」などと入力して「OK」をクリックします。

 3. 「URL」欄を次の内容に書き換えて「OK」をクリックします。
    幅と高さは変更しなくてかまいません。

      http://localhost:8765/

 4. プレビュー画面の中で、ドラッグして位置や大きさを調整します。
    文字は枠の大きさに合わせて拡大・縮小します。

 これで導入は完了です。


------------------------------------------------------
 見た目を変える（お好みで）
------------------------------------------------------

 青いアイコンを右クリックして「見た目を変える」を選ぶと、
 ブラウザーで設定の画面が開きます。

  ・フォント、文字の色、縁取り、大きさ、位置
  ・数字が変わるときのアニメーション（増えると上へ、減ると下へ）
  ・増えたときの演出（光る、きらきら、紙吹雪、自分の画像・動画）
  ・背景（透明、単色、画像、動く画像、動画）

 画面のプレビューで「＋1 増やす」などを押すと、動きを試せます。
 「保存して OBS に反映」を押すと、OBS の画面も変わります。

 ※ 背景の動画は webm 形式がおすすめです。
 ※ 人が作ったイラスト・フォント・動画は、配信で使ってよいか
    利用条件を確認してください。


======================================================
 毎回の使い方
======================================================

 配信を始めるとき
   1. 「SubCounter.exe」をダブルクリック
   2. OBS を起動

 配信が終わったら
   タスクトレイ（画面右下の時計の近く）の青いアイコンを右クリックして
   「終了」を選ぶ

 ※ ツールには画面がありません。アイコンが見当たらないときは、
    時計の近くの「^」をクリックしてください。
 ※ ツールを起動していないと、OBS に数字は表示されません。


======================================================
 知っておくと安心なこと
======================================================

 ・数字の確認は 1 分ごとです。ただし YouTube 側の更新には時間が
   かかるので、すぐには画面が変わらないことがあります。

 ・API の無料枠（1 日 10,000 回）の範囲に十分収まります。

 ・一度数字が表示されたら、問題が起きても OBS にエラーは出ず、
   直前の数字を表示し続けます。
   原因はアイコンのメニューの一番上で確認できます。

 ・利用規約とプライバシーポリシーは、アイコンのメニューの
   「利用規約とプライバシー」からいつでも確認できます。


======================================================
 困ったときは
======================================================

 Q. OBS に「初期設定をしてください」「API キーを確認してください」
    「チャンネルを確認してください」と出ている
    青いアイコンを右クリックして「設定を開く」を選び、内容を直して
    保存してください。

 Q. 「YouTube Data API v3 が有効になっていません」と表示された
    初期設定の画面のリンクから「有効にする」を押してください。
    そのあと、アイコンの右クリックから「今すぐ取得し直す」を選びます。

 Q. OBS に「登録者数が非公開になっています」と出ている
    YouTube の設定で登録者数を公開にしてから、アイコンの右クリックで
    「今すぐ取得し直す」を選んでください。

 Q. OBS に「---」と出ている
    インターネットの不調などで、まだ数字を取得できていません。
    自動でやり直すので、そのままお待ちください。

 Q. OBS に何も表示されない
    1. タスクトレイに青いアイコンがありますか？
       なければ exe を起動してください。
    2. OBS の URL は http://localhost:8765/ になっていますか？
    3. OBS のソース一覧で、ブラウザソースが非表示
       （目のマークが消えた状態）になっていませんか？

 Q. 「API の 1 日の上限に達しました」と表示された
    API の無料枠を使い切っています。翌日（日本時間の 16 時か 17 時）に
    自動で再開します。

 Q. 「すでに起動している可能性があります」と表示された
    ツールはすでに動いています。もう一度起動する必要はありません。

 Q. ツールを削除したい
    1. アイコンのメニューから「終了」を選びます。
    2. 展開したフォルダーをごみ箱に入れます。
    3. キーボードの「Windows キー」と「R」を同時に押し、次の文字を
       入力して「OK」をクリックします。
         %LOCALAPPDATA%
    4. 開いたフォルダーの中の「SubCounter」を削除します。
    5. 不要になった API キーは、Google Cloud の「認証情報」の画面で
       削除してください。
