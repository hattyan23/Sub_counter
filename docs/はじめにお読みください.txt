======================================================
 YouTube 登録者数カウンター  導入手順
======================================================

YouTube チャンネルの登録者数を 1 人単位で、OBS の配信画面に
表示するツールです。

導入は 4 ステップで、10 分ほどで終わります。
難しい設定やコマンド入力はありません。


------------------------------------------------------
 始める前に用意するもの
------------------------------------------------------

 [ ] Windows のパソコン（Windows 10 / 11）
 [ ] Google Chrome
     入っていない場合は https://www.google.com/chrome/ から
     インストールしてください。
 [ ] OBS Studio
     入っていない場合は https://obsproject.com/ja/ から
     インストールしてください。
 [ ] 登録者数を表示したい YouTube チャンネルの Google アカウント


------------------------------------------------------
 ステップ 1：ファイルを展開する
------------------------------------------------------

 ※ zip を開いただけの状態では正しく動きません。必ず展開してください。

 1. ダウンロードした zip ファイルを右クリックします。
 2.「すべて展開」をクリックします。
 3.「展開」ボタンをクリックします。
 4. 同じ名前のフォルダーができます。
    この中に「YouTubeSubCounter.exe」があれば成功です。

 ヒント：デスクトップなど、あとで見つけやすい場所に置いてください。
         「_internal」フォルダーは動作に必要です。消したり、
         exe と別の場所に移したりしないでください。


------------------------------------------------------
 ステップ 2：ツールを起動する
------------------------------------------------------

 1.「YouTubeSubCounter.exe」をダブルクリックします。

 2. 青い画面で「Windows によって PC が保護されました」と出た場合は、
    次の順にクリックすると起動できます。
      「詳細情報」→「実行」
    （個人が配布しているソフトのため表示されることがあります）

 3. 画面右下に「起動しました」という通知が出ます。
    ツールには画面がなく、画面右下のタスクトレイ（時計の近く）に
    赤いアイコンとして常駐します。

    アイコンが見当たらないときは、時計の近くにある「^」を
    クリックすると表示されます。


------------------------------------------------------
 ステップ 3：Google にログインする（最初の 1 回だけ）
------------------------------------------------------

 1. 起動すると、案内のメッセージと Chrome のウィンドウが自動で
    開きます。メッセージは「OK」で閉じてください。

 2. 登録者数を表示したいチャンネルの Google アカウントで
    ログインします。

 3. YouTube Studio の画面（ダッシュボード）が表示されたら、
    Chrome のウィンドウを右上の × で閉じます。

    ★ 閉じるまで次に進みません。必ず閉じてください。

 4. 次回からはログインなしで使えます。


------------------------------------------------------
 ステップ 4：OBS に表示する（最初の 1 回だけ）
------------------------------------------------------

 1. OBS を開きます。

 2. 画面下の「ソース」欄にある「+」をクリックします。

 3.「ブラウザ」を選びます。

 4. 名前に「登録者数」などと入力して「OK」をクリックします。

 5. 設定画面で次のように入力します。

      URL  ：  http://localhost:8765/
      幅   ：  800
      高さ ：  200

    ヒント：URL は、タスクトレイの赤いアイコンを右クリックして
            「OBS 用の URL をコピー」を選ぶと、コピーできます。

 6.「OK」をクリックします。

 7. 20 秒ほどで登録者数が表示されます。
    プレビュー画面の中で、ドラッグして位置や大きさを調整できます。

 これで導入は完了です。


======================================================
 毎回の使い方
======================================================

 配信を始めるとき
   1.「YouTubeSubCounter.exe」をダブルクリック
   2. OBS を起動

 配信が終わったら
   タスクトレイの赤いアイコンを右クリックして「終了」を選ぶ

 ※ ツールを起動していないと、OBS に数字は表示されません。


======================================================
 知っておくと安心なこと
======================================================

 ・数字の更新は約 1 分ごとです。登録者が増減しても、YouTube 側の
   反映を含めて、画面が変わるまで数分かかることがあります。

 ・パスワードはこのツールには保存されません。
   ログイン状態は Chrome の仕組みで、このパソコンの中だけに
   保存されます。

 ・取得に失敗したときは、OBS にエラーは出ず、直前の数字を
   表示し続けます。


======================================================
 困ったときは
======================================================

 Q. OBS に何も表示されない
    次の順に確認してください。
    1. タスクトレイに赤いアイコンがありますか？
       なければ exe を起動してください。
    2. 起動してから 30 秒ほど待ちましたか？
    3. OBS の URL は http://localhost:8765/ になっていますか？
       すべて半角で、打ち間違いがないか確認してください。
    4. OBS のソース一覧で、ブラウザソースが非表示
       （目のマークが消えた状態）になっていませんか？

 Q. 急に Chrome のウィンドウが開いた
    ログインの有効期限が切れた合図です。もう一度ログインして、
    Chrome を閉じてください。自動で再開します。

 Q. ログインせずに Chrome を閉じてしまった
    タスクトレイのアイコンから「終了」を選び、exe を起動し直して
    ください。もう一度 Chrome が開きます。

 Q.「すでに起動している可能性があります」と表示された
    ツールはすでに動いています。もう一度起動する必要はありません。
    タスクトレイに赤いアイコンがない場合は、パソコンを再起動してから
    試してください。

 Q. 起動したのに何も表示されない
    このツールには画面がありません。タスクトレイに赤いアイコンが
    あれば、正常に動いています。

 Q.「Google Chrome が見つかりません」と表示された
    Chrome をインストールしてから、もう一度起動してください。

 Q. 別のチャンネルの数字が表示される / アカウントを変えたい
    次の手順でログインをやり直してください。
    1. タスクトレイのアイコンから「終了」を選びます。
    2. キーボードの「Windows キー」と「R」を同時に押します。
    3. 次の文字を入力して「OK」をクリックします。
         %LOCALAPPDATA%
    4. 開いたフォルダーの中の「YouTubeSubCounter」を削除します。
    5. exe を起動し、表示したいチャンネルのアカウントで
       ログインします。

 Q. ツールを削除したい
    1. タスクトレイのアイコンから「終了」を選びます。
    2. 展開したフォルダーをごみ箱に入れます。
    3. 上の手順 2〜4 で「YouTubeSubCounter」フォルダーも削除します。
       これでログイン情報も消えます。
