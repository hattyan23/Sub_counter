プライバシーポリシー

本ソフト「登録者数カウンター」の情報の取り扱いについて説明します。

YouTube API Services の利用

本ソフトは YouTube API Services を使用しています。本ソフトを利用することで、 YouTube 利用規約に拘束されることに同意したものとみなします。 Google による情報の取り扱いは Google プライバシー ポリシーをご確認ください。

取り扱う情報

  • 入力された API キーとチャンネル ID
  • YouTube API Services から取得したチャンネルの登録者数
  • 動作の記録（エラーの種類や時刻）
  • 見た目の設定と、見た目のために追加された画像・動画・フォント

情報の使い方と保存場所

  • API キーとチャンネル ID は、登録者数を取得するためだけに使い、お使いのパソコンの中に保存します。
  • 登録者数は画面に表示するために使い、ファイルには保存しません。本ソフトを終了すると消えます。
  • 動作の記録には、API キーと登録者数を含めません。
  • 見た目の設定と追加されたファイルは、お使いのパソコンの中に保存し、どこにも送信しません。

第三者への提供

API キーとチャンネル ID は、登録者数の取得のために Google に送信されます。本ソフトの配布者を含め、それ以外の第三者には送信しません。 本ソフトはアクセス解析や Cookie を使用しません。

情報の削除

本ソフトを終了し、次のフォルダーを削除すると、保存された情報をすべて消せます。

%LOCALAPPDATA%\SubCounter

API キーは Google Cloud の「認証情報」の画面で削除できます。
