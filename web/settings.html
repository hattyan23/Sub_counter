初期設定

このソフトは YouTube API Services を使って登録者数を取得します。入力した内容はこのパソコンの中にだけ保存します。

1. 利用規約とプライバシー

2. API キー

無料で作れます。お金はかからず、クレジットカードの登録や「無料トライアル」も必要ありません。

  1. Google Cloud でプロジェクトを作る（名前は自由。初めてのときは国と利用規約の確認が出ます）
  2. YouTube Data API v3 のページで「有効にする」を押す（画面上のプロジェクト名が 1 で作ったものか確認）
  3. 認証情報のページで「＋ 認証情報を作成」→「API キー」を選ぶ
  4. 表示された「AIza」で始まるキーをコピーして、下に貼り付ける

画面ごとの詳しい手順は、同梱の「導入ガイド.pdf」の「API キーの作り方」に載っています。

「AIza」で始まっていません。プロジェクト ID やクライアント ID ではなく、API キーをコピーしたか確認してください。

API キーはパスワードと同じです。人に教えたり、配信に映したりしないでください。

3. チャンネル

次のどれかを貼り付けてください。

  • ハンドル（例：@yourname）
  • チャンネルページの URL
  • チャンネル ID（UC で始まる 24 文字）
