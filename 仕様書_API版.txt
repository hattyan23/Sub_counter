YouTube登録者数カウンター 開発仕様書（公式API方式）

1. 開発目的

YouTubeチャンネルの登録者数を取得し、OBS上に独自デザインのカウンターとして表示するツールを開発する。

登録者数の増減に応じて、数字が上方向にスライドするオドメーター式アニメーションを実装する。

今回は規約遵守を優先し、YouTube公式APIのみを使用する方式に変更する。

2. 最重要要件

* YouTube公式APIを利用すること。
* YouTube Studioのスクレイピング、DOM解析、未公開API、内部通信の直接利用は禁止。
* YouTube Data APIの仕様に従った登録者数を取得する。
* 登録者数の取得は自動更新とする。
* OBS上に独自デザインのカウンターを表示する。
* 登録者数が変化した際、数字が上方向にスライドするアニメーションを実装する。
* OBS起動時にカウンターも利用可能な状態にする。
* Chromeを手動で起動する必要がない構成にする。
* YouTube Studioを画面上に表示する必要がない構成にする。
* 規約遵守を前提とし、公式APIの制限を回避しない。

3. 使用技術

以下を基本構成とする。

* YouTube Data API v3：登録者数取得
* Python：取得処理・バックグラウンドアプリ
* HTML / CSS / JavaScript：カウンター表示
* OBS Browser Source：カウンター表示
* ローカルHTTPサーバーまたはWebSocket：Pythonから表示側へのデータ連携

必要に応じて技術構成の変更は可能だが、公式API利用の要件は維持すること。

4. 登録者数取得仕様

YouTube Data API v3のchannels.listを使用する。

取得対象：

* statistics.subscriberCount

取得対象チャンネルは設定可能にする。

登録者数取得時には、YouTube公式APIの丸め仕様を理解したうえで実装すること。

登録者数の丸め仕様

登録者数は1,000人を超えると有効数字3桁に切り捨てられる。

例：

実際の登録者数	API取得値
999	999
1,234	1,230
12,345	12,300
123,456	123,000

この制限を回避する方法は実装しない。

5. カウンター表示仕様

* 独自デザインのカウンターを作成する。
* 背景透過に対応する。
* 登録者数を数字で表示する。
* 数字が変化した際、オドメーター式の上方向スライドアニメーションを実装する。
* 桁ごとにアニメーションさせる。
* OBS Browser Sourceで表示できること。
* HTML/CSS/JavaScriptで表示部分を独立させる。

6. 更新仕様

* 登録者数を一定間隔で取得する。
* API呼び出し頻度はクォータ制限を考慮する。
* API取得失敗時には最後に取得した数値を保持する。
* エラー発生時に過剰なAPI呼び出しを行わない。
* API取得値が変化した場合にのみ表示アニメーションを実行する。
* API取得値が変化しない場合は表示を維持する。

7. API認証・設定

* Google Cloud ConsoleでYouTube Data API v3を有効化する。
* APIキーを使用する。
* APIキーはソースコードに直接埋め込まず、設定ファイル等で管理する。
* チャンネルIDを設定可能にする。
* APIキーや設定ファイルの取り扱いに注意する。

8. 開発フェーズ

Phase 1：公式API取得検証

* Google Cloud Consoleの設定手順を確認する。
* YouTube Data API v3の利用準備を行う。
* チャンネルIDを指定して登録者数を取得する。
* APIレスポンスの確認を行う。
* APIの丸め仕様を確認する。
* クォータ消費量を確認する。

Phase 2：カウンター表示

* HTML/CSS/JavaScriptで独自カウンターを作成する。
* オドメーター式のアニメーションを実装する。
* 背景透過に対応する。
* API取得値を表示側に連携する。

Phase 3：OBS連携

* OBS Browser Sourceで表示する。
* 表示サイズを調整可能にする。
* 背景透過を確認する。
* 数字のアニメーションを確認する。

Phase 4：自動起動・運用

* バックグラウンドアプリの起動方法を整える。
* OBS起動時に必要なアプリも起動できるようにする。
* API取得失敗時の処理を実装する。
* 設定変更やログ出力を整える。

9. 最初に実施する内容

まずPhase 1のみ実施すること。

YouTube Data API v3を利用して登録者数を取得する最小構成を作成し、動作確認を行う。

この段階ではOBS連携やアニメーションは実装しない。

最終目標は、YouTube公式APIで取得した登録者数を、独自デザインのアニメーション付きカウンターとしてOBSに表示することである。
